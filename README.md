## About this website

This repository contains the source for my personal portfolio.

- **Frontend:** React, TypeScript, and Vite
- **Styling:** Tailwind CSS and a custom dark visual theme
- **Motion:** Motion for React
- **3D:** Spline scene embedded in the hero section
- **Icons:** Lucide React
- **Deployment target:** Vercel

The design aims to stay minimal and readable while using motion and 3D as accents rather than letting them overpower the content.

## Run it locally

You'll need a recent version of **Node.js** and npm. Replace `YOUR-REPOSITORY` below with the actual GitHub repository name.

```bash
git clone https://github.com/timus1424/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
npm install
npm run dev
```

Vite will print a local development URL in your terminal.

To create a production build:

```bash
npm run build
```

The generated site is written to `dist/`.

## Spline scene

The hero section uses a publicly hosted Spline scene. The scene itself is loaded remotely, so visitors need an internet connection to see it. If you replace the scene, update the Spline URL in `src/app/components/Hero.tsx` and test the experience on mobile and lower-powered devices.
